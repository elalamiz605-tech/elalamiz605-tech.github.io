# Ziad El Alami · Portfolio

Personal portfolio of **Ziad El Alami**, junior full-stack developer based in Madrid.

🌐 **Live site:** https://elalamiz605-tech.github.io

## Features

- One-page responsive layout: hero, services, projects, contact
- English / French language toggle (remembers the visitor's choice)
- Contact form that opens the visitor's email app (no server, no data stored)
- Animated starfield background and scroll-reveal effects (disabled for users who prefer reduced motion)
- No framework, no build step: plain HTML, CSS and JavaScript

## Tech stack

HTML5 · CSS3 · Vanilla JavaScript · GitHub Pages

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Structure

```
index.html      Page content (English text, translated by script.js)
style.css       Brand styles: #05060D night, #6D3FD8 violet, #67E8F9 cyan
script.js       Language toggle, contact form, animations
assets/logo.svg ZE planet logo
```
